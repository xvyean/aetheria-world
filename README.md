## 这一版改了什么

- **设定推倒重写。** 不再是女神大战虚空之蛇 + 霍格沃茨四院。四院是四个答案（花掉 / 写成字 / 打进铁里 / 还回海里），分选问的是“这一年的光你要花在什么上”，暮影是还清了贷因此不再投下影子的人。
- **学院用 Blender 重做。** `blender/engine/` 生成船岛（账桅、四院回廊、退字阁、浮池、观星台、旧舟）。`models/academy.glb` 在世界地图和学院页里各加载一次。夜景成图在 `renders/`。
- **学院页是可点的 3D 视口。** 点建筑看志，昼 / 暮切换。
- 三块大陆、十四势力、四十二城的地图还在，文案全部按新设定重写。

## 本次重构：从"网页建模"到"真正的三维资产"

旧版（v3）的星槎学院是 Three.js 里用圆柱+圆锥+球体**临时拼出来**的，被称作"建模垃圾"确实不冤。本次重构彻底重做：

| 维度 | 旧版 | 重构版 |
|---|---|---|
| 学院建模 | 圆的+锥的+球的小摆件 | **Blender 程序化精细建模**：83,843 面 · 17 个分区 · 39 种材质 |
| 设定 | "最高学府"式空泛描述 | **七卷设定圣经**（bible/）：世界之骨、学院总志、四院谱、建筑志、大事记、飞升之卷、术语审计 |
| 世界观连接 | 设定与模型脱节 | 建筑志=施工说明书：每座建筑/每处形制都有设定依据与材质规范 |
| 媒介 | 只有网页 | `Blender 工程(.blend)` + `GLB 资产` + `网页查看器` + `渲染成品` 四件套 |
| 交付 | 无资产 | `models/academy.blend` · `models/academy.glb` · `renders/` 六机位×三氛围 · `bible/` |

## 为什么值得看

**星槎学院是"一笔八百年的账"** —— 不是学校，是仲裁所、翻译局、专利局、银行、监狱、赌场、码头（多数现在还当着）。本重构把每一栋楼都建入了这个设定：

- **星陨塔**（34 米 · 八角三收 · 带开缝的铜绿观景穹顶 + 裂隙晶）：塔内第一层有**回声井**——向下喊，回上来的不是你的声音。
- **浮池**：悬在岛缘的石盆，水永远满、永远平。池边 14 座石座刻着历代"托住自己"者的名字。池里不许捞"星影"。
- **星穗馆**（圆馆 · 金穹顶 · 七层）：一层收"被删到只剩七个字的原稿"；七层夜间须烬人在场。
- **四院回廊**：四条坡道连廊，尽头院门无锁、半开——"门开着，是规矩，也是考验。"
- **宿舍环**：21 栋四色小屋，编号从 14 直跳 16——**第 22 栋的位置只有一圈旧地基**（谜二：缺席的宿舍）。
- **山门**（双石柱+弧形楣+守门像）、**吊篮泊位**（上下岛的路）、**白板墙**（写下的必须是真的）、**钟楼**（锈擦不掉的沉钟）、**名士墓**（坟市——每年擦三块碑）。

**十 个谜**（bible/05-飞升之卷）：813 斤、第 22 栋、回声井、裂隙晶的问题、会挪书的书、提前的四十年、第 211 号自荐生、擦不掉的锈、第 41 片水晶、校长在等谁。

## 快速开始

### 网页版（需本地服务器加载 GLB）
```bash
# 在项目根目录
python3 -m http.server 8899
# 浏览器打开 http://localhost:8899/world-modern.html
```

### Blender 资产
```bash
# 构建（生成 models/academy.blend）
python3 blender/build.py --build

# 渲染（输出到 renders/，三氛围×六机位）
python3 blender/build.py --render

# 导出 GLB
python3 blender/build.py --export
```

需要 Python 3.9+ 且有 `bpy`（Blender 5.2 的 Python 模块；`pip install bpy`），或直接从 Blender 的内置 Python 运行。

## 世界观 · 一页

星辉历 412 年。星陨创世后，最大星辰碎片坠于主大陆北缘，成为**星辉裂隙**——一切星辉（魔法之源）的伤口与源流。裂隙正上方三百丈，悬着一块升空八百多年未落的台地：**星槎学院**。六族每年送来学生（多是"天字一号人质"），台地是仲裁所、翻译局、专利局、银行、监狱、赌场、码头。星辉潮汐十二年一次，大潮将至；裂隙纹路十年宽了"两指"；暮影海峡的雾今年飘得离主大陆近了三十里。

**四院**：晨辉（启 · 序）、星语（言 · 删）、锤音（锻 · 誓）、海心（怀 · 潮）。四色金/绿/铜/蓝。分选礼在试读年次年春分夜的星陨塔第七层。

更多见 `bible/`。
