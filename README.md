## 世界概览

> “当最后一颗星辰坠入大海，所有的光，都在这里醒来。”
> ——《白冠圣典 · 第一卷》

艾瑟兰（Aetheria）是一个高奇幻世界：星辉女神陨落后，她的血与泪化作星辰碎片坠入大海，大地自虚空中隆起，最大的碎片成为世界中央的**星辉裂隙**——一切魔法（星辉）的源头。

**五族一影**共享这片大陆：

## 功能特性

### 三维世界地图
- 🌍 **程序化地形**：fBm 噪声 + 山脊噪声生成大陆、山脉（铁砧山脉）、海岸与雪线，每次打开布局一致（确定性种子）
- 🗺️ **种族分布可视化**：六大地理单元按种族领地渲染不同地貌与植被密度（精灵森林、兽人荒原、暮影暗土……）
- 🏰 **七大城市地标**：白冠城王座、千岁梧桐王庭、熔心圣殿、雷牙图腾、金麦圆顶屋、寂灭之塔、星辉圣所
- 💎 **星辉裂隙**：世界之心——发光晶簇、光柱、旋转星环、浮空岛与上升粒子
- 🌊 动态海面着色器、大气雾效、体积光晕
- 🌗 **黎明 / 正午 / 星夜** 三档氛围切换（平滑过渡；夜间城市信标与裂隙显著增亮，星空浮现）
- ✨ 星辉流：从裂隙通往六大城市的流光航线
- 🖱️ 轨道相机（旋转 / 缩放 / 平移）、自动环绕、点击城市打开志书卡片、悬停提示

## 本地运行

无需构建，直接打开或起一个静态服务器：

```bash
# 方式一：直接打开
open index.html          # macOS
start index.html         # Windows
xdg-open index.html      # Linux

# 方式二：静态服务器（推荐）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

> Three.js r128 已内置于 `vendor/` 目录，**无需联网、无需 npm 安装**。
> 建议桌面端 Chrome / Edge / Firefox 现代版本，带 WebGL 的显卡体验最佳。

## 技术说明

| 模块 | 实现 |
| --- | --- |
| 地形 | 220×220 段平面，fBm(5) + ridged(5) 山脊噪声，边缘径向衰减沉入海洋；城市周围自动凿谷并平整 |
| 种族分布 | 六区域软权重（smoothstep 混合）驱动顶点色、植被密度与山体强度 |
| 性能 | 树木 / 建筑使用 `InstancedMesh`（单次绘制数千实例），2048 PCF 软阴影 |
| 氛围 | 天空 / 海面 / 雾 / 光照 / 星空 / 发光体由统一状态机插值切换 |
| 渲染 | sRGB 输出 + ACES 色调映射 |
