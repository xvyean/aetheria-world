## 世界概览

> “当最后一颗星辰坠入大海，所有的光，都在这里醒来。”
> ——《白冠圣典 · 第一卷》

艾瑟兰（Aetheria）是一个高奇幻世界：星辉女神陨落后，她的血与泪化作星辰碎片坠入大海，大地自虚空中隆起。最大的碎片落在大陆北缘，成为**星辉裂隙**——一切魔法（星辉）的源头，也是第一大河**星辉河**的源流。

星辉历 412 年，大陆为**十四势力**共有——同一血脉的种族分裂为多个王国，彼此割据、结盟、嵌居：

| 种族 | 势力 | 领地 |
| --- | --- | --- |
| 人类 | 白冠王国 · 灰港公国 · 晨晖主教区 · 碎浪群岛 | 中央平原 / 南岸河口 / 东原 / 东南群岛 |
| 精灵 | 银叶王国 · 月影林地 | 熔川以东（翡翠林海）/ 熔川以西（柳林） |
| 矮人 | 熔心城邦 · 铜脊部族 | 铁砧山脉之心 / 东南崖壁（两山互不相邻） |
| 兽人 | 黑牙战团 · 血誓部族 | 西部风暴荒原 / 南部雾沼边缘 |
| 半身人 | 金麦谷 · 麦浪商盟 | 南部谷地 / 白冠境内飞地 |
| 暮影族 | 暮影领（禁域） | 极北暗土 |
| （万族） | 星辉教团 | 裂隙旁的中立圣地 |

三河两湖贯穿大陆：**星辉河**自裂隙流出、穿白冠城七丘、在灰港入海；**熔川**分两林而治，川上不许立桥；**夜语溪**出暮影暗原、过雾沼注入西海。**星落湖**深不见底，湖心比岸上多三颗星的倒影；**镜渊湖**平如明镜，圣骑士在此照镜验誓。

## 功能特性

### 三维世界地图
- 🌍 **程序化大陆**：有机海岸线（扰动椭圆掩膜 + 西部荒原半岛 + 碎浪群岛 + 礁岛），fBm + 山脊噪声塑造铁砧山脉、高原与丘陵，内陆地板杜绝“内海”
- 🏞️ **真实水文学**：星辉河/熔川沿指定流域蜿蜒入海（河口三角洲），夜语溪水力追踪自然成溪；星落湖/镜渊湖碗状湖盆 + 环湖抬坝
- 🗺️ **十四势力领地**：噪声扰动 Voronoi 疆界，各势力专属地貌配色与植被密度；势力之外的**荒野**边缘地带
- 🏰 **十四座城**各具地标：白冠七塔与跨河石桥、灰港灯塔栈桥、晨晖黄金大教堂、碎浪礁岩要塞与风车、千岁梧桐王庭、垂柳村月石环、熔心圣炉、铜脊崖壁双塔、雷牙图腾、百鼓营、金麦圆顶粮仓、麦浪钟塔集市、寂灭黑塔、星辉星尖圣殿
- 🏘️ 二十余处**村庄**散布各势力腹地
- 💎 **星辉裂隙**：世界之心——发光晶簇、光柱、旋转星环、浮空岛与上升粒子
- 🌫️ **雾沼**沼泽着色，暮影晶簇环绕寂灭之塔
- 🌊 动态海面着色器、大陆架渐隐、大气雾效
- 🌗 **黎明 / 正午 / 星夜** 三档氛围平滑切换（夜间信标、晶簇与星辉流显著增亮，星空浮现）
- ✨ 星辉流：从裂隙通往十三城的流光航线
- 🖱️ 轨道相机（旋转 / 缩放 / 平移）、自动环绕、点击城市打开志书卡片、图例点击飞赴势力疆域

## 本地运行

无需构建，直接打开或起一个静态服务器：

```bash
# 方式一：直接打开
open index.html          # macOS
start index.html         # Windows
xdg-open index.html      # Linux

# 方式二：静态服务器（推荐）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

> Three.js r128 已内置于 `vendor/` 目录，**无需联网、无需 npm 安装**。
> 建议桌面端 Chrome / Edge / Firefox 现代版本，带 WebGL 的显卡体验最佳。

## 技术说明

| 模块 | 实现 |
| --- | --- |
| 地形 | 320×320 段大陆网格（1000 单位世界），扰动掩膜海岸 + 山脊山脉 + 内陆地板 |
| 河流 | 指定流域沿走廊蜿蜒 + 河道幂等雕刻 + 河口挖通；自由溪流用 8 方向最速下降水力追踪；湖盆碗形雕刻 + 环湖抬坝 |
| 势力分布 | 14 中心噪声扰动 Voronoi（top-2 权重边界混合），飞地加权；顶点色 / 植被密度 / 建筑配色同源驱动 |
| 性能 | 树木 / 建筑 / 村庄 `InstancedMesh`（数千实例单次绘制），4096 PCF 软阴影 |
| 氛围 | 天空 / 海面 / 雾 / 光照 / 星空 / 发光体由统一状态机插值切换 |
| 渲染 | sRGB 输出 + ACES 色调映射 |
| 确定性 | 全部噪声与摆放使用固定种子（`srand` 线性同余），每次打开布局一致 |
