## 二、反 AI 味清单（自检，写作与文案强制）

**禁用**：命运的齿轮 / 古老的预言 / 觉醒 / 万年之前的宿命 / 守夜人的低语（除非真有守夜人且他真低语）/ 数值化模板（耗光 82、记账 48 这类属性表——已删除）/ 四元素风火水土对号入座 / 排比式口号 / 省略号"深沉体" / "传说中…""据说…"无宾语堆砌 / 语录一律加出处与年份。

**提倡**：文牍体（年册、批注、账单、契书）；具体数字（813 斤、两指、七个字、108 面鼓）；互相矛盾的证词；不解释的规矩；生活细节（澡堂热水、晾衣绳、柴堆、欠账榜）；人物说话带口癖（顾言 ≤7 字、巴林记账腔、柯蕾塔的海上腔）。

**判定**：一段文案若删去"奇幻词汇"后只剩空话，即判不合格，重写。

1. **纪年统一**：旧网页 data.js / index.html / academy.js 混用"余光历"——**全部改为星辉历**（世界之骨：白冠之誓后 1212 年 = 星辉历 412 年）。"余光"一词仅保留为意象（"余光未尽"作标题可，作历法不可）。

4. **校长语录**：旧 README 引"卫晚潮，星槎学院第十九任校长"——**保留**（作为校史引文），但当前校长为**凯兰·星羽（第 ? 任，档案未载在任序数，他本人不说）**——旧版称"第二十一任"为误，删。
